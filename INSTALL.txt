Guide d'installation du client Smartelia
=====================================

Ce guide explique comment installer le client Smartelia sur un Mac. Le client s'exécutera automatiquement au démarrage et enverra périodiquement les informations de la machine au serveur.

Prérequis
---------
- Un Mac avec macOS
- Les droits administrateur (sudo)
- Une connexion Internet

Étapes d'installation
-------------------

1. Préparation des fichiers
   ------------------------
   - Copier le fichier host_client.sh dans le répertoire /usr/local/bin/
   - Copier le fichier com.smartelia.hostclient.plist dans le répertoire /Library/LaunchDaemons/

   Commandes à exécuter :
   ```bash
   sudo cp host_client.sh /usr/local/bin/
   sudo cp com.smartelia.hostclient.plist /Library/LaunchDaemons/
   ```

2. Configuration des permissions
   ----------------------------
   - Rendre le script exécutable
   - Définir les bonnes permissions pour le fichier plist

   Commandes à exécuter :
   ```bash
   sudo chmod +x /usr/local/bin/host_client.sh
   sudo chmod 644 /Library/LaunchDaemons/com.smartelia.hostclient.plist
   ```

3. Configuration des logs
   ---------------------
   - Créer les fichiers de logs nécessaires
   - Définir les permissions appropriées

   Commandes à exécuter :
   ```bash
   sudo mkdir -p /var/log
   sudo touch /var/log/host_client.log
   sudo touch /var/log/host_client.err
   sudo touch /var/log/host_client.out
   sudo chmod 666 /var/log/host_client.*
   ```

4. Activation du service
   --------------------
   - Charger le service dans launchd

   Commande à exécuter :
   ```bash
   sudo launchctl load /Library/LaunchDaemons/com.smartelia.hostclient.plist
   ```

Vérification de l'installation
----------------------------

1. Vérifier que le service est actif :
   ```bash
   ps aux | grep host_client.sh
   ```

2. Vérifier les logs :
   ```bash
   cat /var/log/host_client.log
   ```

Gestion du service
----------------

Pour arrêter le service :
```bash
sudo launchctl unload /Library/LaunchDaemons/com.smartelia.hostclient.plist
```

Pour démarrer le service :
```bash
sudo launchctl load /Library/LaunchDaemons/com.smartelia.hostclient.plist
```

Pour redémarrer le service :
```bash
sudo launchctl unload /Library/LaunchDaemons/com.smartelia.hostclient.plist && sudo launchctl load /Library/LaunchDaemons/com.smartelia.hostclient.plist
```

Désinstallation
-------------

Pour désinstaller complètement le client :

1. Arrêter le service :
   ```bash
   sudo launchctl unload /Library/LaunchDaemons/com.smartelia.hostclient.plist
   ```

2. Supprimer les fichiers :
   ```bash
   sudo rm /usr/local/bin/host_client.sh
   sudo rm /Library/LaunchDaemons/com.smartelia.hostclient.plist
   sudo rm /var/log/host_client.*
   ```

Notes importantes
---------------
- Le client s'exécute automatiquement au démarrage du Mac
- Les informations sont envoyées au serveur toutes les heures
- Les logs sont conservés dans /var/log/host_client.log
- En cas de problème, vérifier les logs pour plus d'informations

Support
-------
En cas de problème, vérifier :
1. Les logs dans /var/log/host_client.log
2. Que le serveur est accessible
3. Que la connexion Internet fonctionne
